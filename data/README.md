# Datos

Este proyecto utiliza imágenes radiológicas empleadas en pruebas de control de calidad en radioterapia.

Por razones de confidencialidad y cumplimiento ético, los datos reales no se incluyen en este repositorio.

El análisis está diseñado para trabajar con:
- Imágenes en escala de grises
- Variaciones de intensidad asociadas al campo luminoso y al haz de radiación
- Resoluciones típicas de placas radiológicas de control de calidad

La estructura del código permite sustituir los datos reales por imágenes simuladas o de prueba sin modificar el flujo principal del análisis.
